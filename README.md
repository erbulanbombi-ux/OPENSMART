# 🧠 OPENSMART — Персональный AI-ассистент в Telegram

**OPENSMART** — это интеллектуальный Telegram-бот нового поколения для управления целями, структурирования заметок, планирования дня и глубокой концентрации на задачах.

Разработано специально для хакатона с акцентом на высокую автономность, проактивность и защиту от ошибок.

---

## 🌟 Ключевые возможности

### 1. 🎯 Долгосрочные цели и задачи (`/tasks`)
* **Система этапов и прогресса**: визуальные прогресс-бары `[████░░░░] 50%` и статусы (*Не начата*, *В процессе*, *Приостановлена*, *Завершена*).
* **ИИ-декомпозиция**: если цель сформулирована расплывчато (например, *«Учить английский»*), ИИ задаёт уточняющие вопросы и формирует реалистичный план из 5 этапов.
* **История завершённых этапов**: сохранение точного времени и хронологии выполненных шагов (`/tasks view <ID>`).
* **Быстрое продвижение**: `/tasks advance <ID>` переключает цель на следующий шаг.

### 2. 📝 Умные заметки и идеи (`/notes`)
* **Создание обычным сообщением**: напишите боту `Заметка: Купить билеты #планы` или `Запиши: Идея для стартапа #идеи` — бот автоматически распознает мысль, извлечёт теги `#хэштег`, присвоит ID и зафиксирует дату.
* **Полнотекстовый поиск и теги**: поиск по ключевым словам и категориям (`/notes search`).
* **Просмотр и редактирование**: `/notes view <ID>`, `/notes edit <ID> | новый текст`.

### 3. 🗑 Безопасное удаление информации (`/forget`)
* **Удаление конкретных записей**: поиск заметок, воспоминаний или целей без полного сброса бота.
* **Предпросмотр перед удалением**: бот находит записи и показывает карточку или список совпадений.
* **Защита от случайного удаления**: удаление происходит **строго** после явного ответа `YES` (или `ДА`). Любой другой ответ отменяет операцию.

### 4. ☀️ Ежедневный помощник (`/daily`)
* Анализирует цели, дедлайны и заметки.
* Выделяет блок **«Что лучше сделать первым»** на основе приоритетов и сроков.
* Не перегружает пользователя лишними сообщениями.
* Автоматическая утренняя сводка в **08:00** в часовом поясе пользователя.

### 5. ⏱ Фокус-сессии (`/focus`)
* Таймер глубокой концентрации на 1–180 минут (`/focus 25`).
* Мягкий трекинг задачи и напоминание о возвращении к делу при отвлечении.

## 🚀 Быстрый запуск через Docker (Рекомендуется для жюри)

Запуск проекта одной командой:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/erbulanbombi-ux/OPENSMART.git
   cd OPENSMART
   ```

2. Создайте файл `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```
   Укажите ваши ключи в `.env`:
   ```env
   BOT_TOKEN=ваш_telegram_bot_token
   OPENROUTER_API_KEY=ваш_openrouter_api_key
   CHECKIN_TIMEZONE=Europe/Moscow
   ```

3. Запустите через Docker Compose:
   ```bash
   docker compose up -d --build
   ```

Данные и память бота автоматически сохраняются в Docker volume.

---

## 💻 Локальный запуск без Docker

1. Установите Python 3.11+:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # На Windows: .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

2. Заполните `.env` файл.

3. Запустите бота как модуль:
   ```bash
   python -m bot.main
   ```

## ⚙️ Переменные окружения (`.env`)

| Переменная | Обязательная | Описание | По умолчанию |
|---|:---:|---|---|
| `BOT_TOKEN` | Да | Токен бота от [@BotFather](https://t.me/BotFather) | — |
| `OPENROUTER_API_KEY` | Да | API ключ OpenRouter (или OpenAI) | — |
| `LLM_MODEL` | Нет | Используемая языковая модель | `openai/gpt-4o-mini` |
| `LLM_BASE_URL` | Нет | Базовый URL API | `https://openrouter.ai/api/v1` |
| `CHECKIN_TIMEZONE` | Нет | Часовой пояс (IANA) | `UTC` |
| `CHECKIN_HOURS` | Нет | Часы чек-инов через запятую | `9,14,20` |

## 📋 Список команд бота

* `/start` — Инициализация и знакомство
* `/tasks` — Управление целями, прогрессом и этапами
* `/notes` — Хранилище заметок, идей и тегов
* `/forget` — Безопасное удаление конкретной записи (с подтверждением `YES`)
* `/daily` — Сводка задач на день и фокус дня
* `/focus <мин>` — Запуск таймера продуктивности (1–180 минут)
* `/new` — Сброс контекста диалога
* `/memory` — Текущее состояние контекста
* `/help` — Подробная справка по всем функциям
